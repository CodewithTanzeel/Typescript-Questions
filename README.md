## 🎯 About

The **TypeScript Questions** repository is a structured 100-day coding challenge that provides:

- **112+ TypeScript questions** across all difficulty levels
- **190+ TypeScript code examples** and exercises
- **199+ Markdown files** with detailed explanations
- **Progressive learning path** from basics to advanced concepts
- **Real-world scenarios** and interview preparation materials

Whether you're a beginner starting your TypeScript journey or an experienced developer looking to sharpen your skills, this repository offers a systematic approach to mastering TypeScript.

## 🚀 Getting Started

### Prerequisites
- Basic knowledge of JavaScript
- Node.js installed (v14 or higher)
- A code editor (VS Code recommended)

### Quick Start
1. **Clone the repository:**
   ```bash
   git clone https://github.com/CodewithTanzeel/Typescript-Questions.git
   cd Typescript-Questions
   ```

2. **Install TypeScript globally:**
   ```bash
   npm install -g typescript
   ```

3. **Start with Day 1:**
   ```bash
   cd 01/q1
   # Read the question.md file and start coding!
   ```

4. **Compile and run TypeScript:**
   ```bash
   tsc yourfile.ts
   node yourfile.js
   ```

Perfect for those new to TypeScript:
- Basic syntax and type annotations

- Functions and basic operations

- Advanced types and interfaces

### 🌳 Advanced Path (Days 71-100)

- Performance optimization
- Real-world application development
